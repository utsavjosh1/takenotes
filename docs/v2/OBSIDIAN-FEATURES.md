## Per-feature REA notes (inference vs unknown)

- **Fuzzy scoring (Quick Open/Palette/Search ranking):** Obsidian's exact scorer is **unknown** (no bundle trace in v2). Reconstruction specifies *behavior-compatible* fuzzy (subsequence + adjacency + recency boost, always-fuzzy, capped display) and tests vectors, never byte parity.
- **Index internals (metadata cache layout, incremental granularity):** unknown. Reconstruction specifies the *contract* (parse-once per workspace, `workspaceId+relativePath` identity, revision-hash guards, bounded 2000-file/1MiB caps with visible notices) and lifecycle tests.
- **Graph layout forces:** unknown constants. Reconstruction specifies *readable* forces + required filters/groups/depth, not identical coordinates.
- **Sync/Publish wire formats:** unknown and out of scope (paid-service boundary). v2 never claims them.
- **Pin semantics** above are **derived** from Help ("links from pinned tab open separately") + takenotes single-strip constraint (no splits/pop-outs in MVP): the only compatible reading is *pinned tab is never replaced; target opens as/activates another tab; bulk-close preserves pinned*. Implemented accordingly.
- **Evernote mapping** is **derived** from the public `.enex` DTD (notes/resources/tags) + our Step 8 import contract (attachment mapping, link conversion outcomes, never-fetch-remote, never-overwrite). No Obsidian Importer binary was traced; behavior parity is at the *outcome* level (Markdown + attachments + report), not code parity.
