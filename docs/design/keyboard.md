# Keyboard — takenotes

| Keys | Action |
|---|---|
| `Ctrl+N` | New note |
| `Ctrl+P` / `Ctrl+O` | Quick open |
| `Ctrl+Shift+P` | Command palette |
| `Ctrl+S` | Save |
| `Ctrl+W` | Close tab |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous tab |
| `Ctrl+\` | Toggle sidebar |
| `Ctrl+.` | Focus mode |
| `Ctrl+,` | Settings |
| `Ctrl+F` | Find in note (CodeMirror search) |
| `F2` | Rename selected file |
| `Delete` | Move selected file to trash |
| `↑ ↓ → ← Enter` | Tree + palette navigation |
| `Esc` | Close topmost transient layer |

Notes: `Ctrl+K` was considered for palette but conflicts with link insertion
conventions; palette stays on `Ctrl+Shift+P`. `Ctrl+.` chosen for focus mode
after checking VS Code (`breadcrumb`) and browser (no default) conflicts —
exposed in palette regardless. All shortcuts listed in palette + Shortcuts
settings tab. Tab order: title-bar search → rail → sidebar → tabs → editor →
status. Every focusable element has an accent focus ring in both themes.
